# Pixel art sources

31개 SVG의 원본은 `grids/*.json`입니다. 각 파일의 `palette`는 문자 하나를
불투명 RGB 색상으로 매핑하며, `rows`의 문자 하나가 원본 1px입니다.
`.`은 투명 픽셀입니다. 격자를 직접 수정하면 됩니다. PNG나 외부 폰트,
이미지 라이브러리, 난수 생성에 의존하지 않습니다.

```sh
# 저장소 루트에서; Python 3 표준 라이브러리만 필요
python3 tools/art/generate.py
python3 tools/art/generate.py --check
```

변환기는 같은 색의 가로 연속 픽셀을 묶고, 동일한 가로 구간을 세로로
합쳐 `<rect>`로 출력합니다. 같은 색은 `<g fill>`로 묶습니다.
`width`, `height`, `viewBox`, `shape-rendering="crispEdges"`가 항상 설정됩니다.
출력은 결정적이며, 원본 격자와 픽셀 단위로 같습니다. `--check`는 쓰기 없이
31개 목록·크기·색상·반복 경계·바닥 기준점·서로 다른 애니메이션 프레임·
파일당 50,000바이트 미만·생성 결과 일치를 확인합니다.

## 구성

- `player`: 256×32, 32×32 프레임 8개. 대기 0–1, 걷기 2–5,
  상승 6, 낙하 7. 민트 재킷·산호색 스카프·작은 배낭. 오른쪽을 보며
  모든 프레임의 신발 밑면은 31행입니다.
- `coin`: 48×12, 12×12 프레임 4개. 회전하며 폭과 반사광 방향이 변합니다.
- `bg_*`: 480×270의 불투명 배경 6개. 양쪽 경계 색상이 일치하며
  지평선/바닥 기준은 220px, 바다는 약 160px입니다.
- `tile_*`: 32×16 아틀라스 6개. 왼쪽 16×16은 윗면, 오른쪽은 속입니다.
  두 영역 모두 가로로 반복되며 속 타일은 세로로도 반복됩니다.
- 소품 17개: 투명 배경, 아래쪽 기준. 창문·금속·재킷의 밝은 면은
  왼쪽 위를 향합니다. 명세의 파일명과 크기는 변경하지 않았습니다.

배경은 색상 띠와 먼 실루엣으로 낮은 대비를 유지하고, 상호작용 대상은
밝은 테두리·창문·표식으로 구분했습니다. 모든 도형과 격자는 이 작업에서
작성했으며 외부 게임 이미지나 로고는 포함하지 않습니다.

## 브라우저 확인

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

페이지를 열면 기존 로더가 PNG 실패 후 SVG를 사용합니다. 따라서 PNG의
404는 정상이며, SVG 31개가 모두 로드되어야 합니다. 6개 구역, 플레이어
애니메이션, 코인, 소개 창, 모바일 터치 버튼을 확인합니다.

`sign`의 상단 48×20과 `debt_board`의 화면은 명세대로 글씨 없이 두었습니다.
현재 `index.html`은 이 두 소품의 글자/숫자를 임시 도형 함수 안에서만
그리므로 SVG를 사용하면 해당 문구가 표시되지 않습니다. 이는 기존 렌더링
구조의 제한이며, 아트 작업에서는 `index.html`을 변경하지 않았습니다.
